# Alliance Productions India Website

This is the first working website build for Alliance Productions India.

Open `index.html` directly in a browser to preview it.

## What Is Included

- Premium API Royal Cinema visual direction.
- Home page sections for films, people, awards/press, submissions, partner inquiries, and contact.
- Interactive film filtering: Released, In Production, Upcoming.
- Clickable film and people cards with detail panels.
- CMS/admin foundation section showing what the future admin system will control.

## Important Note About The Logo

The supplied logo is the official design direction. The current preview uses a code-native header mark inspired by the supplied logo because the uploaded chat image is not yet available as a project file. For production, save the original logo image into `alliance-productions-india/assets/` and replace the header mark with that file.

## Production CMS Path

The recommended production setup is Payload CMS with Next.js and Postgres. That will let the Alliance team edit:

- Films
- People
- Press
- Awards
- Media
- Project submissions
- Partner inquiries
- Future private investor/deck content

The current file is the visual and structural foundation for that larger CMS build.
